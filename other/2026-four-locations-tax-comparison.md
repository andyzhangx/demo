# 上海、多伦多、BC 与悉尼：收入税收与净收入对比

更新日期：2026-10-24。所有金额除明确标注外均为人民币。

> **这是一份条件测算，不是报税申报结果或专业税务意见。** 四地分别假设为全年当地税务居民，不涉及同一年迁居、双重税务居民、跨境抵免或股权跨境工作日分摊。中国和加拿大使用2026自然年；澳洲使用2026–27财年。它们并非完全相同的时间区间。
>
> **加拿大主表假设配偶全年净收入为0并符合配偶抵免资格；配偶实际收入尚未确认。** 悉尼净收入尚未扣私人住院保险费、可能适用的Division 293养老金额外税。上海公积金税前额度仍需工资单核实。这些条件会影响排序。

| 项目 | 年金额／条件 |
|---|---:|
| 基本工资 | 880,233 |
| 奖金 | 241,700 |
| RSU归属收入 | 429,728 |
| **税前收入合计** | **1,551,661** |
| 中国家庭扣除 | 独生子女、父母至少一方满60岁；一个8岁孩子，由本人全额申报；符合条件的住房贷款利息 |

RSU按归属收入计税，不把归属收入当作资本利得。未计算归属后出售的额外收益或亏损。净收入包含税后RSU价值，**不等于每月到账现金工资**。

### 汇率

为保持各次对比一致，使用加拿大央行2026-10-23公布的单日汇率：

- 1元人民币 = 0.2098加元；1加元 = 4.766444元人民币。
- 1澳元 = 0.9838加元；交叉汇率1澳元 = 4.689228元人民币。
- 同一税前收入折算为 **325,538.48加元** 或 **330,899.04澳元**。

这不是2026全年平均汇率；正式申报需按当地允许的折算方式计算。

### 悉尼与加拿大的差额

- 对比多伦多：有合规住院保险时，悉尼年净收入高 **53,207元**；无合规住院保险时高 **29,933元**。
- 对比BC：有合规住院保险时，悉尼年净收入高 **19,435元**；无合规住院保险时低 **3,840元**。
- 澳洲以上优势尚未扣保险费及Division 293税。不得据此直接断言澳洲生活可支配收入更高。

## 3. 上海：工资、奖金与合格RSU分别计税

### 3.1 工资扣除

假设全年均符合扣除资格，并按上海社保缴费上限缴纳：

| 工资税前扣除项目 | 全年金额 |
|---|---:|
| 基本减除费用 | 60,000.00 |
| 赡养老人：3,000/月，总额度而非父母各一份 | 36,000.00 |
| 子女教育：一个孩子、本人全额，2,000/月 | 24,000.00 |
| 首套住房贷款利息：1,000/月 | 12,000.00 |
| 个人养老、医疗、失业保险，合计10.5% | 47,270.79 |
| 个人公积金税前允许扣除〔条件值〕 | 54,024.00 |

社保按1–6月基数37,302元/月、7–12月37,731元/月计算：

```text
社保 = (37,302 × 6 + 37,731 × 6) × (8% + 2% + 0.5%)
     = 47,270.79
```

公积金实际个人扣款按用户提供的60,000元保留；税前扣除暂按普通及补充公积金最高合计12%的口径，采用每月4,476元和4,528元的取整结果，全年54,024元。此公积金数值参考2026调整通知的二次转载，**未取得官方公积金原始页面核验**。不应把它当作个人工资单已确认额度。

- 精确按12%乘基数为54,023.76元，与采用54,024元对全年税额影响不足0.10元。
- 5,000元/月是否包含公司缴存、是否有超限缴存，以及雇主超限部分是否需并入工资，都要核对。
- 本文不假设公司另有需并入工资的超限缴存。

### 3.2 分项税额

```text
工资应纳税所得额
= 880,233 − 60,000 − 72,000 − 47,270.79 − 54,024
= 646,938.21

工资个税 = 646,938.21 × 35% − 85,920
         = 140,508.37

年终奖：241,700 ÷ 12 = 20,141.67
适用月换算税率25%，速算扣除数2,660
奖金个税 = 241,700 × 25% − 2,660 = 57,765.00

合格股权激励：全年RSU合计429,728，超过420,000分界
RSU个税 = 429,728 × 30% − 52,920 = 75,998.40

全年个税 = 140,508.37 + 57,765.00 + 75,998.40
         = 274,271.77

全年净收入 = 1,551,661 − 274,271.77 − 47,270.79 − 60,000
           = 1,170,118.44
```

假设奖金全部符合全年一次性奖金单独计税条件且当年仅用一次；RSU符合股权激励单独计税条件、同年多次取得的合格股权激励已合并。两类单独计税均不能重复使用工资的基本及专项附加扣除。相关政策有效期至2027-12-31。

在该组合下，年终奖单独计税比把全年奖金并入工资少交26,830元。

**更正前文：** 429,728元RSU应适用30%而非25%；正确税额为75,998.40元。本文还更新了下半年社保基数。因此本文上海总额替代此前使用全年统一37,302元基数的估算。

## 4. 加拿大：工资、奖金、RSU合并纳税

### 4.1 共同参数

- 税前就业收入：325,538.48加元。
- CPP基础部分3,519.45加元；增强部分711加元；CPP2为416加元。
- CPP总计4,646.45加元；EI为1,123.07加元。
- 可作为所得扣除的增强CPP及CPP2为1,127加元；应税收入324,411.48加元。
- 已计入适用的个人基本抵免、联邦就业金额抵免，以及基础CPP/EI抵免。
- 未计入RRSP、托儿费用、捐赠、其他配偶转移额度等未提供项目。
- 中国的赡养老人、子女教育、自住房房贷利息扣除不能直接套用加拿大。

### 4.2 配偶全年净收入为0的抵免

配偶抵免是按规定抵免率计算的non-refundable tax credit，**不是夫妻平分收入后分别使用累进税率表**。

| 项目 | 安省，加元 | BC，加元 |
|---|---:|---:|
| 联邦节税：14,829 × 14% | 2,076.06 | 2,076.06 |
| 省级节税，安省含附加税联动减少 | 868.86 | 633.75 |
| 合计节税 | 2,944.92 | 2,709.81 |
| 折合人民币 | 14,036.82 | 12,916.17 |

安省配偶额11,029加元，按5.05%抵免，并在本收入水平同时减少20%+36%的附加税，因此省级节税为11,029×5.05%×1.56。BC配偶额11,317加元，按5.60%抵免。

2026年配偶收入影响：
- 联邦：在本人的高收入情况下，配偶净收入达到14,829加元时本项抵免降至0。
- 安省：配偶净收入不超过1,103加元可用完整省级额度，达到12,132加元时降至0。
- BC：配偶净收入不超过1,132加元可用完整省级额度，达到12,449加元时降至0。

配偶净收入需按税务规则确定，不能只看在加拿大工作的工资，境外收入也可能影响额度。

## 5. 悉尼：2026–27财年

假设全年澳洲税务居民、适用Medicare且没有豁免。新南威尔士州不再叠加加拿大式州个人所得税。

| 应税收入，澳元 | 边际税率 |
|---|---:|
| 0–18,200 | 0% |
| 18,200–45,000 | 15% |
| 45,000–135,000 | 30% |
| 135,000–190,000 | 37% |
| 超过190,000 | 45% |

```text
收入 = 330,899.04澳元
个人所得税 = 51,370 + (330,899.04 − 190,000) × 45%
           ≈ 114,774.57澳元
Medicare Levy = 收入 × 2% ≈ 6,617.98澳元

无合规住院保险：额外MLS = 收入 × 1.5% ≈ 4,963.49澳元
```

### 私人住院保险

2026–27财年、一个受抚养孩子的家庭，最高档MLS家庭收入门槛为328,001澳元。按本文汇率，即使配偶无收入，本人收入也超过该门槛，所以全年无合规保险时采用1.5%附加税。

- 合规私人住院保险通常不能免掉基础2%的Medicare Levy。
- 避免MLS通常需要本人、配偶及受抚养孩子均获得符合要求的住院保险覆盖。
- 牙科、眼科等extras-only保险不能替代合规住院保险。
- 主表假设覆盖或未覆盖为全年；部分年度覆盖需分天计算。
- 澳元收入接近该家庭税档边界，换汇或扣除变化可能影响实际适用档位。

### 雇主super和Division 293

不把雇主super自动当成员工工资再扣12%。若薪酬是含super总包，应先拆分；本文未计入雇主额外养老金的财富价值，也未计养老金账户内部一般缴款税。

本人收入超过250,000澳元，通常会涉及Division 293，对适用的优惠税率养老金缴款额外征收15%。具体税基还需实际缴款及税务调整信息。

例如，若30,000澳元相关缴款全部适用，额外税为4,500澳元，约21,102元人民币。这只是示例，不是断言2026–27缴款上限或实际公司缴款。该税可按规定选择从super账户或个人资金支付。主表未扣此税，不能把澳洲栏视为全部税负后的最终收入。

### 1,000澳元instant tax deduction

2026–27官方预算说明了此项工作收入扣除。主表未认定个人资格、未纳入该扣除；若符合最终适用规则，且不与已申报实际工作费用重复，可能少交约470–485澳元的所得税及相关医疗税费。正式申报前需核实。

## 6. 比较边界与需要补充的信息

1. **加拿大配偶收入**：主表为零收入情景，实际数值未确认。
2. **上海工资单**：核对上下半年社保实际扣款、公积金个人/单位拆分、可税前扣除额及是否存在单位超限缴存。
3. **澳洲offer**：确认收入是否含super、实际雇主缴款、Division 293税额、家庭住院保险及保费。
4. **税年不同**：中国/加拿大2026自然年与澳洲2026–27财年不是同一时间区间；不能直接用于2026年中迁居税表。
5. **跨境税务**：不涉及税收居民身份冲突、双边税收协定、境外税额抵免及跨国RSU服务期分摊。
6. **不是生活成本比较**：不包含房租、房贷实际支出、教育、医疗自费和各地生活成本。
7. **税率并非总福利比较**：没有估值养老金权益、公积金用途、雇主福利或政府家庭补贴。
