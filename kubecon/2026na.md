### Authorized? It Depends.

所属议程：**Maintainer Track / Auth**。根据官方摘要，本场主要讨论：

- **条件授权（Conditional Authorization）**：让授权决策表达“满足条件才允许／拒绝”，介绍部分求值、条件从 authorization 到 admission 的传递、`kubectl auth can-i` 中的展示，以及通过 CEL 在 API server 内求值。
- **Admission webhook 身份验证**：以 IngressNightmare（CVE-2025-1974）为背景，介绍 API server 如何使用限定 API group、绑定 webhook 的 ServiceAccount token 向 webhook 证明身份。
